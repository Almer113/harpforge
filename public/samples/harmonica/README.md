# Harmonica samples

Hohner Special 20 in C, blow notes C4–C7 ("Normal" sustains), from the
**Versilian Community Sample Library (VCSL)** by Versilian Studios:
https://github.com/sgossner/VCSL — `Aerophones/Free Aerophones/Harmonica-Hohner-Special20-C`.

License: **CC0 1.0 Universal** (public domain). No attribution is required; this note is a courtesy.

Processed by `scripts/prepare-samples.py`: octave labels corrected (VCSL's "C3" is middle C),
leading silence trimmed, a seamless loop found and crossfaded, loudness matched, converted to
22.05 kHz mono 16-bit WAV. Loop points and tuning offsets are in `manifest.json`. Draw notes are
pitch-shifted from the nearest recorded note at playback time.
